
# Nassau Candy Distributor
## Factory Reallocation & Shipping Optimization Recommendation System

### Project Overview
A data-driven decision-support system that evaluates alternative factory assignments and generates factory reallocation recommendations.

### Objectives
- Compare current and alternative factory assignments.
- Analyze factory relocation distances.
- Evaluate demand, sales, cost and gross profit.
- Simulate alternative factory scenarios.
- Generate factory recommendations.
- Present results through an interactive dashboard.

### Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Streamlit

7. Data Visualization

### How to Run
Install dependencies:

pip install -r requirements.txt

Run dashboard:

streamlit run 26_streamlit_dashboard.py

### Important Note
Factory relocation distance represents the distance between current and alternative factories. It is not a verified customer shipping-distance saving.

### Conclusion
This project demonstrates the application of Python-based analytics and interactive visualization to support factory allocation decisions.
